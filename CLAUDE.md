# CLAUDE.md

Guidance for Claude Code (claude.ai/code) when working in this repo.

## Commands

```sh
# Evaluate all packages without building (fast validation)
nix flake check --no-build

# Build all packages
nix flake check

# Build a single package
nix build .#<pname>

# Format all .nix files
nix fmt

# Check formatting without modifying
nix run .#formatter -- --check $(git ls-files '*.nix')

# Enter dev shell (nixfmt, nix-update, nil)
nix develop

# Update a package's hash/version
nix-update <pname>

# Regenerate gemset.nix for a Ruby bundler package
cd pkgs/by-name/<prefix>/<pname> && bundix -l
```

## Architecture

### Package discovery

`pkgs/default.nix` auto-discovers everything under `pkgs/by-name/` — no manual registration. Each package lives at `pkgs/by-name/<2-char-prefix>/<pname>/package.nix` where prefix = first two chars of package name. `callPackage` called with `pkgs // { inherit lib; }` so packages receive extended `lib` (see below).

### Extended lib

`lib/default.nix` extends nixpkgs `lib` with `lib.skyepkgs.*` helpers:
- `mergePackageSets` — deep-merges list of package-set attrsets
- `isValidPackageName` — assertion helper

### vimPlugins

`pkgs/vim-plugins/default.nix` exposes custom neovim plugins built with `vimUtils.buildVimPlugin`. Surfaced as `legacyPackages.vimPlugins.<name>` in flake (not `packages`), merged with `nixpkgs.vimPlugins` in overlay so `pkgs.vimPlugins.<name>` works when overlay applied.

### Ruby/bundler packages

Ruby packages use nixpkgs `bundlerApp`. Each package dir contains `Gemfile`, `Gemfile.lock`, `gemset.nix`. `gemset.nix` generated by `bundix -l` — must regenerate whenever `Gemfile.lock` changes (CI does this automatically on push to main).

### Overlay

`overlay.nix` applies all packages onto nixpkgs, merges `vimPlugins` with `prev.vimPlugins` (additive, not replacing). Consumers apply via `nixpkgs.overlays = [ skyepkgs.overlays.default ]`.

### Home Manager modules

`modules/home-manager/` contains Home Manager modules. `opencode-monitor.nix` exported as both `homeManagerModules.opencode-monitor` and `homeManagerModules.default`.

### CI

`.github/workflows/validate.yml` — runs `nix flake check --no-build` on Linux and macOS on every push/PR.  
`.github/workflows/update-gemset.yml` — auto-regenerates `gemset.nix` and pushes commit when `Gemfile`/`Gemfile.lock` changes on main.
